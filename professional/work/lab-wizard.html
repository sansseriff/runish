Lab Wizard

Experiment setup for SNSPD measurement labs: typed instrument models, a version-controllable config tree, and generated, runnable measurement projects.

Docs ↗GitHub ↗

Lab measurement code tends to grow as a pile of one-off scripts, each with instrument addresses and settings hard-coded inside. Lab Wizard replaces that with a structured workflow: add instruments to a configuration tree, edit their parameters to match the bench, then create a measurement by picking a template and assigning compatible instruments to it.

Each measurement becomes its own project folder with exactly the configuration it used and a generated Python file that wires everything up. The generated code is meant to be read and edited, so the tool speeds up setup without hiding what it does.

The app is a FastAPI backend serving a SvelteKit frontend inside a pywebview window. Procedures can be composed in the UI from reusable steps, with parameters, presets and instrument roles, and exported to plain Python.

Highlights

  • Typed Python models for instruments, including parent/child and channel-based hardware.
  • A user-owned YAML configuration tree per workspace, so a lab’s hardware setup is explicit, diffable and reviewable.
  • Measurement templates that turn a choice of instruments into a timestamped project folder with its own config subset and a generated setup script.
  • An instrument server that owns each hardware transport, with safety rules that block unsafe calls (for example, biasing a detector while a shutter is open).
  • One-line install on macOS and Linux, a native desktop window, and a launcher that shows the window in a fraction of a second.
