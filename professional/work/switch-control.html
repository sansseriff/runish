Switch Control

Desktop and remote control for a cryogenic 1→8 RF switch: a binary tree of latching relays driven from outside the fridge.

Docs ↗GitHub ↗

Superconducting detectors are measured in a cryostat that takes many hours to cycle. The switch puts seven latching relays at the cold stage in a binary tree, so one differential input can be routed to any of eight devices without warming up.

The control program sends pulses through a USB relay board, tracks which path is open, and draws the relay tree so that the current route is obvious at a glance. Labels, settings and pulse-generator status all live in one backend state model that browser clients subscribe to.

Highlights

  • Testing throughput for mid-IR SNSPDs went up eightfold: eight devices measured per cooldown instead of one.
  • A single reactive state model on the backend, streamed to the UI as JSON patches over a WebSocket, with no polling.
  • Remote access through single-use, five-minute invitation links (QR codes) and Argon2id-hashed passphrases.
